# Pully — Solo Agent Run (WORK IN PROGRESS)

**Status:** M1 (Core Loop) Code Complete — Unity scenes need manual wiring or run `Pully/Setup Game`

## Quick Start for Unity

1. **Open Unity 6 LTS**
2. **Import TextMeshPro** when prompted
3. **Open Menu Scene:** Assets/_Game/Scenes/MenuScene.unity
4. **Run Setup:** Click menu `Pully/Setup Game` to generate:
   - Ruleset ScriptableObject
   - Target prefabs (Circle, Square, Triangle, Star)
   - GameScene and GameOverScene with UI
   - Build Settings
5. **Build APK:** Click `Pully/Build Android (Debug)` or run:
   ```
   Unity -quit -batchmode -projectPath . -executeMethod Builder.BuildAndroid
   ```
